# 同行成长 2.0 · Aca × QuantLife 整合版

面向朋友、自律小组的个人成长与正向监督应用。统一主题色 **#DCE2F1 / RGB(220,226,241)**，采用浅色卡片、深蓝操作按钮，手机五栏导航：今日、成长、小组、账本、我的。

本版是可运行的整合开发与内测版本，尚未完成服务器上线、浏览器视觉验收、手机真机及商店审核。线上 V12 页面保持原状。

## 已完成的功能

- 账号：用户名/密码注册登录、12小时网页会话恢复、改密退出全部设备、数据导出与删除。部署模式需要内部注册口令。
- 今日：北京时间签到、近7天签到、本月/累计/最长连续；任务搜索、编辑、归档、优先级、截止日期；单次/每天/每周/每月/每年任务。
- 成长：1～12个自定义维度、小时经验系数、雷达图、7天图表、行动记录、近期历史、主线进度与领奖、成就、奖励商店及库存使用。
- 小组：创建/邀请/加入、退出排名、转让组长、移除成员；周行动榜、坚持榜、同期进步榜；前台每30秒刷新，可手动刷新。
- 账本：多笔同日收入/支出，编辑、删除、分类备注，今天/7天/本月/累计统计；以整数分保存金额；期初余额与财富目标。
- 导入：预览 Aca V9–V12、QuantLife 和整合版 JSON；追加或替换个人空间；按文件摘要去重；保留原始导入文件到本人导出中。QuantLife 实际使用的 `daily.days`、月任务、年任务均已映射。
- AI：可选的目标拆解与行动文字整理，默认关闭；仅发送用户明确提交的文字，建议需要本人检查后保存。
- 部署准备：Docker/Caddy HTTPS配置、原生来源白名单、注册口令、在线SQLite备份、Android/iOS工程配置、Windows运行环境与自动测试入口。

## 三种数值各司其职

| 数值 | 获取与用途 |
| --- | --- |
| 个人经验 | 签到、行动、任务、主线提升；兑换奖励不扣经验 |
| 奖励点 | 与新获得的个人经验同步增加，兑换后扣减 |
| 小组积分 | 签到每天1分，专注25分钟/学习20分钟/活动15分钟各2分；每天最多7分 |

个人签到每天+1，连续每满7天额外+3；该奖励不放大小组签到分数。普通任务/AI/导入经验不进入排行榜。固定行动同步产生个人记录与小组积分。所有完成记录仍是本人自报，系统防重复计分不等于证明实际行动。

## Windows 最快启动

1. 将完整包解压到一个新文件夹，不要直接覆盖旧目录。
2. 进入 `mobile`，双击 `INSTALL-AND-TEST-WINDOWS.cmd`，等待 `Overall: PASS`。
3. 双击 `START-WINDOWS.cmd`，打开 http://127.0.0.1:8787 。保持命令窗口开启。
4. 注册账号。本机开发模式的“内部注册口令”留空；服务器模式使用管理员提供的口令。
5. 在“我的”导入旧存档。先导出旧数据，再预览并确认导入。

Windows x64 完整包附带 Node.js 24.21.0，不需要管理员权限。安装脚本校验官方 Node 可执行文件 SHA-256。本机核心程序不依赖 `npm install`，只需 Node.js 24。

原联机开发版账号迁移：停止旧服务，把旧 `mobile/data` 整个目录备份，再复制到新包对应位置。启动时自动新增个人空间表，保留账号、小组、签到和积分。不要在两个进程中同时运行同一份数据目录。

V12 个人版：在原页面导出JSON后导入。QuantLife：使用自己的 `fengdingding-progress.json`，不要上传 `llm-config.json`（可能含密钥）。

如果8787已被旧服务占用，先停止旧窗口，或在PowerShell使用：

```powershell
$env:ACA_DEV_PORT='8788'
.\START-WINDOWS.cmd
```

## 导入规则与限制

- **追加**：旧维度作为独立维度加入，不擅自把“商业”与“学习”等不同分类合并。合计最多12维。财富期初余额保留当前设置，请在账本中自行确认。
- **替换**：覆盖当前个人空间，但账号、小组、服务端签到与排名积分不变。请先导出当前数据。整合版备份仅支持替换。
- 已有经验进入期初值，旧历史记录保留原经验字段但不再加经验。QuantLife 没有对应奖励点余额，因此不会把旧经验直接换成奖励点。
- 导入文件的SHA-256防止同文件重复导入；修改后的同类文件属于新文件，追加前要自行核对是否含同一批历史。不同文件之间没有语义去重保证。
- 原存档的未映射字段（例如旧的洞察或特殊设置）在导出文件 `importedOriginals` 中保留，不代表都有独立界面。
- 上限：12维、2000任务、200主线、30000成长记录、10000收支、200奖励；单次导入JSON最大8MB。超限停止写入。

## 测试与原生工程

```sh
node scripts/verify.mjs
```

包括17组应用测试、SQLite备份恢复、V12回归、网页构建。结果在 `test-results/latest.txt`。具体本轮执行范围见 `TEST-REPORT.md`。

原生依赖与工程：

```sh
npm ci --ignore-scripts --no-audit --no-fund
npm run native:android
```

该命令首次生成Android工程，再次运行同步现有工程。不会删除已有原生工程。iOS用 `npm run native:ios`；iOS编译需macOS/Xcode。API未配置时，原生界面会提示尚未部署后端。配置方式见 `deploy/README.md`。

## 服务器与持久化

本地数据位于 `mobile/data/club.sqlite`，与用户账号关联，包含私密记录。不提交Git、不包含在交付包。可配置 `ACA_DATA_DIR` 指向持久目录。线上单服务器部署步骤在 `deploy/README.md`。

```sh
node scripts/backup.mjs
```

在线备份会生成独立一致的SQLite文件到 `backups`。请另存安全位置。此版本没有自助密码找回、推送通知、多服务器横向扩展、已验证的原生长期登录或商店签名。

服务默认本机运行，没有购买服务、发送邀请、上传用户私有存档或替用户注册付费账号。
