# 同行成长 · 本地开发验证版 0.1

面向中国大陆朋友／自律小组的邀请制成长应用。本次只完成免费开发验证，不购买云资源、不修改线上 V12、不提交应用商店。

## 本版可以验证什么

- **真实账号**：用户名、昵称、密码注册和登录。密码使用随机盐与 scrypt 哈希；会话随机生成，服务端只保存哈希，12 小时过期。
- **真实持久化**：Node.js 24 自带 SQLite，重启服务保留账号、签到、行动和小组。无需安装数据库或付费云服务。
- **邀请码小组**：最多 5 组、每组 30 人；单次邀请，24 小时过期，生成新码使旧码失效。收件人先预览，再确认加入。
- **公平计分**：北京时间签到 +1；专注 25 分钟、学习 20 分钟、活动 15 分钟各 +2，每项每天一次，总计每天最多 7 分。服务端选择日期和分数，唯一约束防止重复提交。
- **三种组内榜单**：本周行动榜、本周坚持榜、个人进步榜。同分同名次，周一重新统计；进步值为本周至今分数减上周同期分数。
- **边界清楚**：个人 V12 能力值、自定义任务和收支不上传参榜。任何任务完成仍是本人自报，防重复计分不能证明实际行为。
- **自主参与**：退出参榜、退出小组、组长转让、移除成员、导出个人数据、改密并退出全部会话、账号删除。
- **移动端页面**：小屏底部导航、大按钮、明确空状态、登录错误和隐私说明。没有虚构成员、假排名或预置真实用户。

## Windows 最快启动

1. 解压开发包，进入 `mobile` 文件夹，双击 **`INSTALL-AND-TEST-WINDOWS.cmd`**。脚本从 Node.js 官方站点下载 Node.js 24.21.0，校验固定 SHA-256，并安装到本目录的 `.runtime`；支持 Windows x64/ARM64，不修改系统 PATH，不需要管理员权限。首次需要联网下载约 38 MB。
2. 等待自动测试通过，再双击 **`START-WINDOWS.cmd`**。已经安装 Node.js 24 的用户也可以直接启动。
3. 等控制台显示启动成功，在浏览器打开 **http://127.0.0.1:8787**。
4. 保持命令窗口打开；测试完成按 `Ctrl+C` 停止。

安装完成后会自动检测 SQLite、运行功能测试和构建网页资源，结果写入 `test-results/latest.txt` 和 `latest.json`。失败会返回非零退出码，不会显示测试成功。删除 `.runtime` 可移除本项目专用运行环境，不影响用户数据库。

这不等于远程安装到你的电脑。已执行和未执行的项目见 [TEST-REPORT.md](TEST-REPORT.md)。若单位策略限制 PowerShell 或官方下载不可达，不要关闭安全设置；可由管理员安装官方 Node.js 24 后运行下方命令。

命令行方式（Windows/macOS/Linux 通用）在 `mobile` 目录运行：

```sh
node server/main.mjs
```

**本地启动和测试不需要 `npm install`。** `package.json` 中的 Capacitor 依赖只用于后续生成原生工程，本轮已安装并锁定 Capacitor 8.5.3，且已在 Linux 生成与同步 Android 工程；未编译 APK，也未验证 iOS。

如端口被占用，可设置 `ACA_DEV_PORT` 后启动（例如 PowerShell：`$env:ACA_DEV_PORT=8788`）。此服务仅绑定 `127.0.0.1`，不向互联网开放。手机不能通过这里的 localhost 访问电脑。

## 用两个账号验证完整流程

1. 普通浏览器窗口注册测试账号 A；使用虚构昵称和专门的测试密码（12～128 位）。
2. 在“今日”签到，确认只增加 1 分；确认一次固定行动，增加 2 分。
3. 在“小组”建立小组，明确同意组内分享昵称和行动统计，然后生成邀请码。
4. 另开隐私窗口，在同一开发地址注册测试账号 B；预览邀请码，再勾选同意加入。
5. B 完成签到后，A 点击“刷新数据”即可读取 B 的最新分数。**当前不是自动实时推送**。
6. B 退出排名后，A 刷新验证 B 不再出现在榜单中。B 退出小组后不能读取本组榜单。
7. 在“我的”测试导出、修改密码和删除账号；组长仍有组员时须先转让。

登录令牌只放在当前页面内存，**刷新或关闭页面需要重新登录**，服务端数据不受影响。此开发版没有短信、微信登录或忘记密码找回；请记好测试密码。

## 旧版与数据范围

线上 [V12](https://tom0303987-debug.github.io/Aca/) 保持原状。本开发版是独立应用，未复制、迁移或自动上传 V12 本地存档。新账号中的小组积分与 V12 的能力值不是同一种积分。

数据库写入 `mobile/data/club.sqlite`，被 Git 忽略，发布压缩包也不包含数据库。目录本身属于运行服务的电脑；不进行自动云备份。若要备份，应先关闭服务再备份整个 `data` 目录。SQLite 文件未进行应用层加密，请使用测试数据。

删除账号会级联删除其会话、成员关系和计分事件；服务端日志不记录请求体、密码或令牌。已经被其他人截图或导出的数据无法撤回。

## 移动端打包准备（不是已完成安装包）

已经准备 Capacitor v8 配置、响应式页面和网页资源构建脚本。开发包标识 `dev.acagrowth.internal` 只是占位，正式上架前需要确定最终应用名称与唯一标识。

`node scripts/build.mjs` 输出 `dist`。不提供 API 地址时，原生运行会明确提示尚未配置后端，不伪装成功联网。

本轮 Android 工程生成和资源同步已通过。源码包不包含可重新生成的 `node_modules`、`dist`、`android`。在另一台电脑恢复依赖并生成相应工程：

```sh
npm ci --ignore-scripts --no-audit --no-fund
npm run native:android
# 以下步骤只在具备 Xcode 的 macOS 上执行
npm run native:ios
```

按需生成对应平台即可；再次更新资源使用 `npm run native:sync`。本地网页/API 运行不依赖这些安装步骤。依赖版本与完整性校验记录在 `package-lock.json`；请使用 `npm ci` 复现。

**不能直接用现有本机服务做原生发布。** 后续需要部署 HTTPS 后端，配置受控来源、原生会话存储、证书与生命周期，再通过 `ACA_API_BASE` 给构建脚本传入明确的 HTTPS origin。当前 HTTP 服务故意拒绝非本机 Host 和跨源请求；单填一个网址不会解除这些限制，也不会自动创建云服务。

Android 后续需要 Android Studio／SDK 和签名；iOS 后续需要适配的 Xcode／macOS 或相应构建服务、签名与开发者账号。Capacitor 仅提供工程集成，不保证 App Store 审核通过。
